# 乐天 RMS RPP 商品日报：运营交接包

这是供新运营在**自己的 Windows 电脑和获授权的 RMS 账号**上安装的公开代码包。当前功能：自动登录 RMS，下载 RPP 全商品单日报表，在本机生成规则日报，登记定时任务，并在近 30 天窗口内补跑缺失日期。它不是完整的 RMS 数据分析平台，也不包含店铺数据或登录凭据。

**从零安装与验收：请从 [SOP-新运营.md](SOP-新运营.md) 开始。** 不需要访问原运营的私密仓库。

主要文件：

| 文件 | 用途 |
| --- | --- |
| `bootstrap.ps1`、`requirements.txt` | 创建 Python 环境，并在新运营本机录入账号与加密密码 |
| `RMS_FreeDaily.cmd`、`_rms_free_daily.py` | 手动测试与定时日报主程序 |
| `rms_auto_login.py` | 两层 RMS 登录与主菜单确认页 |
| `RMS_RPP_Export.cmd`、`rpp_history.py`、`_rms_check.py` | RPP 控件、下载历史与文件检查辅助程序 |

安全边界：本仓库是公开的，只放通用代码。`.local/` 存放本机账号、DPAPI 加密密码与工具 Chrome 会话；`reports/` 存放店铺报表。这些目录**不得上传**。`.gitignore` 只是误提交保护，不代替人工核对。运行脚本会登录已配置的 RMS 账号；下载或阅读源代码本身不会登录。

验证范围：Python 语法、模块依赖、日期补跑逻辑以及现有样本解析已检查；新运营电脑上的 RMS 页面与定时任务仍需按 SOP 完成首次和次日验收。如果 RMS 改版、要求验证码或账号缺少 RPP 权限，程序会停止并需要人工处理。
